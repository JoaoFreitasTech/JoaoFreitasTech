## Sobre

Desenvolvedor focado em construir aplicações completas, do levantamento de requisitos à publicação. Trabalho com **React** no front-end, **Node.js** no back-end e tenho experiência em **integração de sistemas via APIs** e em conectar aplicações a modelos de IA usando o **Model Context Protocol (MCP)**.

- **Front-end:** interfaces responsivas e componentizadas com React
- **Back-end:** APIs e serviços em Node.js e Python
- **Banco de dados:** modelagem relacional e consultas SQL
- **Integrações:** consumo e construção de APIs REST, autenticação e tratamento de dados em JSON
- **IA aplicada:** servidores e clientes MCP para expor ferramentas e dados a assistentes de IA
- **Versionamento:** fluxo com Git e GitHub — branches, commits organizados e pull requests
- **Base sólida:** lógica de programação em C e Python

📍 Brasília, DF — aberto a oportunidades e projetos freelance
